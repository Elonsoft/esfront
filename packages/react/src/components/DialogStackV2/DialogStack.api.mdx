# DialogStack API

```js
import {
  DialogStack,
  useDialogStackV2 as useDialogStack,
  useDialogStackStateV2 as useDialogStackState,
} from '@esfront/react';
```

The `DialogStack` component renders the dialogs opened through `useDialogStack`. It should be mounted once, at the place
in the tree where the dialogs have to be rendered.
