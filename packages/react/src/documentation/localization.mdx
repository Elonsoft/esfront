# Localization

The default locale is English. If you want to use other locales, pass the locale components to the
`DefaultPropsProvider` to configure the locale text globally:

```tsx
import { DefaultPropsProvider, FormatSize, ru } from '@esfront/react';

const Application = () => {
  return (
    <DefaultPropsProvider value={ru.components}>
      <FormatSize>1024</FormatSize>
    </DefaultPropsProvider>
  );
};
```

A locale is an ordinary provider value, so spread it before your own defaults if you have any:

```tsx
<DefaultPropsProvider value={{ ...ru.components, ESDrawer: { defaultProps: { anchor: 'right' } } }}>
```

You can [find the source](https://github.com/Elonsoft/esfront/blob/master/packages/react/src/components/locale/index.ts)
in the GitHub repository.

To create your own translation, or to customize the English text, copy this file to your project, make any changes
needed and import the locale from there.
