# Hooks

This is a description of every hook exported from `@esfront/react` package. For signatures and usage examples see
typescript declarations files.

| Hook                        | Description                                                                                                                                                                                                                                                                                                                                                    |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| useAudioPlayerContext       | The hook that returns the audio player context. Throws when used outside of `AudioPlayerProvider`.                                                                                                                                                                                                                                                             |
| useBoolean                  | The hook that tracks and toggles value of a boolean.                                                                                                                                                                                                                                                                                                           |
| useBottomSheetContext       | The hook that returns the bottom sheet context. Throws when used outside of `BottomSheet`.                                                                                                                                                                                                                                                                     |
| useCalendar                 | The hook that builds the day grid of a month, together with the trailing days of the previous month and the leading days of the next one that fill the first and the last week.                                                                                                                                                                                |
| useCallbackDebounce         | The hook that creates a debounced function.                                                                                                                                                                                                                                                                                                                    |
| useCallbackThrottle         | The hook that creates a throttled function.                                                                                                                                                                                                                                                                                                                    |
| useClipboard                | The hook that wraps a Clipboard API and exposes read and write methods.                                                                                                                                                                                                                                                                                        |
| useControlled               | The hook that allows to have controlled internal state inside the uncontrolled component.                                                                                                                                                                                                                                                                      |
| useCookie                   | The hook that returns the current value of a cookie, a callback to update the cookie and a callback to remove the cookie.                                                                                                                                                                                                                                      |
| useDateAdapterContext       | The hook that returns the date adapter context. Throws when used outside of `DateAdapterProvider`.                                                                                                                                                                                                                                                             |
| useDebounce                 | The hook that debounces invoking a given callback.                                                                                                                                                                                                                                                                                                             |
| useDialogStack              | The hook that opens dialogs above the current page. `open` returns the dialog `id`, a `close` method and an `afterClosed` promise that resolves with the argument passed to the `close` method of the dialog. The dialogs opened through this hook are closed when the component that opened them unmounts. Throws when used outside of `DialogStackProvider`. |
| useDialogStackContext       | The hook that returns the dialog stack context. Prefer `useDialogStack`, which additionally closes the dialogs a component opened when that component unmounts. Throws when used outside of `DialogStackProvider`.                                                                                                                                             |
| useDialogStackState         | The hook that returns the currently opened dialogs and their number. Throws when used outside of `DialogStackProvider`.                                                                                                                                                                                                                                        |
| useDocumentEventListener    | The hook that sets up a function that will be called whenever the specified event is delivered to the `document`.                                                                                                                                                                                                                                              |
| useDragOver                 | The hook that allows to watch over the drag over state.                                                                                                                                                                                                                                                                                                        |
| useEvent                    | Similar to useCallback, with a few subtle differences: - The returned function is a stable reference, and will always be the same between renders - No dependency lists required - Properties or state accessed within the callback will always be "current"                                                                                                   |
| useForceUpdate              | The hook that returns a function that forces component to re-render when called.                                                                                                                                                                                                                                                                               |
| useForkRef                  | The hook that merges several refs into one.                                                                                                                                                                                                                                                                                                                    |
| useGalleryPanelContext      | The hook that returns the gallery panel context, or `null` when used outside of `GalleryPanel`.                                                                                                                                                                                                                                                                |
| useGalleryPanelsContext     | The hook that returns the gallery panels context. Throws when used outside of `GalleryPanelsProvider`.                                                                                                                                                                                                                                                         |
| useGallerySwiperContext     | The hook that returns the gallery swiper context. Throws when used outside of `GallerySwiperProvider`.                                                                                                                                                                                                                                                         |
| useGalleryThumbnailsContext | The hook that returns the gallery thumbnails context. Throws when used outside of `GalleryThumbnailsProvider`.                                                                                                                                                                                                                                                 |
| useGeolocation              | The hook that that tracks user's geographic location.                                                                                                                                                                                                                                                                                                          |
| useIntersectionObserver     | The hook that provides a way to asynchronously observe changes in the intersection of a target element with an ancestor element or with a top-level document's viewport.                                                                                                                                                                                       |
| useLatest                   | The hook that returns the latest value. This is mostly useful to get access to the latest value of some props or state inside an asynchronous callback, instead of that value at the time the callback was created from.                                                                                                                                       |
| useLocalStorage             | The hook that manages a single `localStorage` key.                                                                                                                                                                                                                                                                                                             |
| useMenu                     | The hooks that returns the common state and callbacks for managing dropdown menus.                                                                                                                                                                                                                                                                             |
| useMenuAim                  | The hook that can differentiate between a user trying hover over a dropdown item vs trying to navigate into a submenu's contents. This hook is inspired by https://github.com/kamens/jQuery-menu-aim.                                                                                                                                                          |
| useMenuVisibility           | The hooks that returns the common state and callbacks for tracking visibility state of dropdown menus.                                                                                                                                                                                                                                                         |
| useMutationObserver         | The hook that provides a way to watch for changes being made to the DOM tree.                                                                                                                                                                                                                                                                                  |
| useOnLine                   | The hook that watches the online status of the browser.                                                                                                                                                                                                                                                                                                        |
| usePagination               | The hook that builds the items of a pagination component: the page numbers, the ellipses and the navigation buttons.                                                                                                                                                                                                                                           |
| usePermission               | The hook that queries permission status of browser APIs.                                                                                                                                                                                                                                                                                                       |
| usePhoneFieldContext        | The hook that returns the libphonenumber metadata of the enclosing `PhoneFieldProvider`. Throws when used outside of it.                                                                                                                                                                                                                                       |
| usePreviousValue            | The hook that receives a variable and outputs its previous value from the last render cycle.                                                                                                                                                                                                                                                                   |
| useRadioGroup               | The hook that returns the state of the enclosing `RadioGroup`, or `undefined` when used outside of one.                                                                                                                                                                                                                                                        |
| useResizeObserver           | The hook that reports changes to the dimensions of an `Element`'s content or border box.                                                                                                                                                                                                                                                                       |
| useScrollDirection          | The hook that tracks scrolling direction of the window or passed container.                                                                                                                                                                                                                                                                                    |
| useScrollLock               | The hook that blocks the scrolling of a container while it is locked, compensating for the width of the scrollbar to avoid a layout shift.                                                                                                                                                                                                                     |
| useScrollSpy                | The hook that observes the intersection of elements with an ancestor or viewport and determines the active one.                                                                                                                                                                                                                                                |
| useScrollSync               | The hook that sync scroll position between multiple elements.                                                                                                                                                                                                                                                                                                  |
| useSessionStorage           | The hook that manages a single `sessionStorage` key.                                                                                                                                                                                                                                                                                                           |
| useSidebarContext           | The hook that returns the sidebar context. Throws when used outside of `Sidebar`.                                                                                                                                                                                                                                                                              |
| useSidebarMenuContext       | The hook that returns the sidebar menu context. Throws when used outside of `SidebarMenu`.                                                                                                                                                                                                                                                                     |
| useSidenavContext           | The hook that returns the sidenav context. Throws when used outside of `Sidenav`.                                                                                                                                                                                                                                                                              |
| useSticky                   | The hook that mimics position sticky via transform.                                                                                                                                                                                                                                                                                                            |
| useStuckSentinel            | The hook that allows to detect sticky element stuck state.                                                                                                                                                                                                                                                                                                     |
| useSwiperContext            | The hook that returns the swiper context. Throws when used outside of `Swiper`.                                                                                                                                                                                                                                                                                |
| useTableBodyContext         | The hook that returns the table body context. Throws when used outside of `Table`.                                                                                                                                                                                                                                                                             |
| useTableCellContext         | The hook that returns the table cell context. Throws when used outside of `Table`, `TableHead` or `TableBody`.                                                                                                                                                                                                                                                 |
| useTableContext             | The hook that returns the table context. Throws when used outside of `Table`.                                                                                                                                                                                                                                                                                  |
| useTableHeadContext         | The hook that returns the table head context. Throws when used outside of `Table`.                                                                                                                                                                                                                                                                             |
| useTableResize              | The hook that manages resizing of the table columns.                                                                                                                                                                                                                                                                                                           |
| useTableScrollbarContext    | The hook that returns the table scrollbar context. Throws when used outside of `Table`.                                                                                                                                                                                                                                                                        |
| useTableSelection           | The hook that manages selection of the table rows.                                                                                                                                                                                                                                                                                                             |
| useThrottle                 | The hook that throttles invoking a given callback.                                                                                                                                                                                                                                                                                                             |
| useTouchRipple              | The hook that drives the touch ripple effect of an element, following the pointer and press state.                                                                                                                                                                                                                                                             |
| useUpdateEffect             | The hook that is similar to `useEffect` but ignores the first invocation.                                                                                                                                                                                                                                                                                      |
| useValueDebounce            | The hook that debounces a given value.                                                                                                                                                                                                                                                                                                                         |
| useValueGate                | The hook that gates a given value.                                                                                                                                                                                                                                                                                                                             |
| useValueThrottle            | The hook that throttles a giver value.                                                                                                                                                                                                                                                                                                                         |
| useVibration                | The hook that activates vibration on mobile device.                                                                                                                                                                                                                                                                                                            |
| useWindowEventListener      | The hook that sets up a function that will be called whenever the specified event is delivered to the `window`.                                                                                                                                                                                                                                                |
