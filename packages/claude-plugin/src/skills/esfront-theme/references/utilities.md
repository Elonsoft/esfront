# Utilities

Utility classes generated by `@esfront/theme/utilities`, included once in the root stylesheet — see [Setup](setup.md).

Which classes exist depends on `$overrides`: `breakpoints` changes the responsive prefixes, `typography` the typography
classes, `utilities` the spacing scales. Check the project's root stylesheet before assuming a class exists.

## Naming

Display, flex, spacing and typography utilities are generated once per breakpoint in `settings.$breakpoints`. The
breakpoint whose value is `0` produces the unprefixed class; every other produces a `{name}:` prefix wrapped in a
min-width query — mobile-first, later breakpoints win. With the default breakpoints: `flex` always, `sm:flex` from
640px, `lg:flex` from 1280px.

Scrollbar utilities are **not** prefixed — there is no `sm:scrollbar-thin-mono-a`.

## Reference

### Display

| Class          | `display`      |
| -------------- | -------------- |
| `hidden`       | `none`         |
| `inline`       | `inline`       |
| `block`        | `block`        |
| `inline-block` | `inline-block` |
| `flex`         | `flex`         |
| `grid`         | `grid`         |

### Flex

| Property          | Classes                                                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------------------- |
| `flex-direction`  | `flex-row`, `flex-row-reverse`, `flex-col`, `flex-col-reverse`                                                |
| `align-items`     | `align-items-` + `start`, `end`, `center`, `baseline`, `baseline-last`, `stretch`                             |
| `justify-content` | `justify-content-` + `start`, `end`, `center`, `between`, `around`, `evenly`, `stretch`, `baseline`, `normal` |

### Spacing

Values are raw pixels, not a step scale: `pt-16` is `padding-top: 16px`. The literal `auto` produces `auto`.

| Classes                             | Property                       | Scale                                                             |
| ----------------------------------- | ------------------------------ | ----------------------------------------------------------------- |
| `pt-` `pb-` `pl-` `pr-` `px-` `py-` | `padding`                      | `auto`, 0, 2, 4, 6, 8, 12, 16, 20, 24, 32, 40, 48, 56, 64, 72, 80 |
| `mt-` `mb-` `ml-` `mr-` `mx-` `my-` | `margin`                       | The same scale as padding                                         |
| `gap-` `gap-x-` `gap-y-`            | `gap`, `column-gap`, `row-gap` | 2, 4, 6, 8, 12, 16, 20, 24, 32, 40                                |

The three scales are configured separately, so `gap` has no `auto` or `0` by default.

### Typography

One class per key of `settings.$typography`, setting `font-size`, `font-weight`, `letter-spacing`, `line-height`,
`text-decoration-thickness` and `text-underline-offset`. Sizes are declared in pixels but emitted in `rem`.

| Levels                                     | Weight variants            |
| ------------------------------------------ | -------------------------- |
| `h1`, `h2`, `h3`, `h4`, `h5`, `h6`         | —                          |
| `subtitle1`, `subtitle2`                   | —                          |
| `body400`, `body300`, `body200`, `body100` | `-w40` (500), `-w50` (700) |
| `caption`                                  | `-w40` (500), `-w50` (700) |
| `mini200`                                  | —                          |
| `mini100`                                  | `-w50` (700)               |
| `micro`, `button`, `overline`              | —                          |

The same levels are available inside a component's SCSS through `level($name)` in `@esfront/theme/helpers/typography`.

### Scrollbars

`scrollbar-{size}-{color}` — all twelve combinations exist, as classes and as same-named mixins in
`@esfront/theme/helpers/scrollbars`.

| Size      | Track                                                                                 |
| --------- | ------------------------------------------------------------------------------------- |
| `normal`  | 16px, with arrow buttons and a visible track background.                              |
| `thin`    | The same as `normal` at 10px.                                                         |
| `overlay` | 14px, transparent track, thumb on hover; sits over the content rather than beside it. |

| Color              | Use for                                       |
| ------------------ | --------------------------------------------- |
| `mono-a`, `mono-b` | Scrollbars that follow the theme.             |
| `black`, `white`   | Scrollbars over fixed dark or light surfaces. |

Colors map to the `--es-{color}-aNNN` alpha variables. See [Colors](colors.md).

## Usage

```tsx
<div className="block sm:flex sm:gap-8 pt-16 lg:pt-32" />
```

- `hidden` sets `display: none`, so `hidden sm:flex` is the idiom for "hide on mobile".
- Flex and grid utilities only set their own property — pair them with `flex` or `grid` yourself.
- Typography levels that define their own breakpoints (`h1`–`h4` by default) already scale on their own; the responsive
  prefix is for switching between levels.
- Scrollbar classes set `overflow: auto` themselves. Inside a component's own SCSS, use the helper mixins rather than
  attaching a utility class.
